# Cyber Security Project

## Password Strength Checker

This project is a simple Password Strength Checker developed using Python. It analyzes a user's password and checks its strength based on different security requirements.

## Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Provides a password strength result
- Helps users understand how to create stronger passwords

## Technologies Used

- Python
- Regular Expressions
- Git & GitHub
